# ⚙️ Programming Techniques | Python Projects

Python-based projects and exercises developed for the **Programming Techniques (Tecniche di Programmazione)** course at **Politecnico di Torino**, covering object-oriented programming, relational databases, graph algorithms, recursion, optimization, and problem-solving applications.

## 📖 Overview

This repository contains a collection of **25 academic projects, laboratory exercises, and examination simulations** developed during the Programming Techniques course.

The projects explore the design and implementation of Python applications, combining software engineering principles with algorithmic problem-solving and data management.

The repository brings together previously separate projects into a single, organized academic portfolio.

## 🎯 Key Competencies

- **Object-Oriented Programming (OOP):** Classes, objects, encapsulation, modularity, and reusable code.
- **Software Architecture:** Model-View-Controller (MVC) architecture and separation of application components.
- **Database Management:** SQL queries, relational databases, and Data Access Object (DAO) integration.
- **Graph Theory:** Directed and undirected graphs, weighted networks, nodes, edges, and graph traversal.
- **Algorithm Design:** Recursion, Depth-First Search (DFS), backtracking, and combinatorial optimization.
- **Problem Solving:** Development of algorithms to analyze data and solve computational problems.

## ⚡ Getting Started

To explore the projects locally, clone the repository:

```bash
git clone https://github.com/mariacerrii/Programming-Techniques.git
```

Navigate into the repository:

```bash
cd Programming-Techniques
```

Open the desired project directory, for example:

```bash
cd FlightDelays
```

Each project has its own structure and may require specific Python packages, datasets, or database configurations.

Some projects use MySQL databases and may require local configuration before execution.
